# Glioblastoma xenobiotic transcriptional score analysis code

Analysis scripts for the public-data reanalysis reported in *A xenobiotic metabolism transcriptional score tracks immune-stromal tissue context in glioblastoma*. The scripts include exploratory discovery steps and the later bulk, GEO, single-cell, spatial and computational composition analyses. They are research code, not a packaged clinical test.

## Data and setup

The raw/processed source data are **not** included here. Obtain the applicable TCGA-GBM and CGGA datasets from their public portals, and GSE16011, GSE149009, GSE131928, GSE237183 and GSE318562 from NCBI GEO. Download the Hallmark, GO and Reactome gene sets used in the analysis from MSigDB, and the MCP-counter signatures/package from the original MCP-counter distribution. Source-study access terms apply. `config/gene_sets.csv` contains the previously defined marker-panel gene list used by these scripts.

The scripts were run in a local analysis workspace. This release replaces machine-specific absolute input roots with environment variables; **the path substitutions have been syntax-checked but not rerun against the full source datasets after relocation**. Set these variables before execution:

| Variable | Meaning |
| --- | --- |
| `JOB49_ROOT` | Root of this analysis workspace, containing `scripts`, `config`, `input` and `results` |
| `JOB46_ROOT` | Root of the upstream prepared TCGA/CGGA and annotated single-cell/spatial data workspace |
| `GEO_LOCAL_ROOT` | Local GEO expression and clinical-file directory |
| `GSE131928_ROOT` | Processed GSE131928 matrix directory |
| `SPATIAL_RAW_ROOT` | Parent directory for GSE237183/GSE318562 raw matrices |

Python dependencies are listed in `requirements.txt`. The R script additionally requires the MCPcounter R package. The optional new-figure builder `scripts/22_build_bmc_extra_figures.mjs` requires Node.js and `sharp`; it consumes the derived CSV results generated by the analysis scripts.

## Order and scope

Scripts `01`–`10` implement the earlier gene/pathway screens and sensitivity checks. Scripts `11`–`18` implement the xenobiotic-focused cross-cohort, spatial, GEO and MCP-counter analyses and figure generation. Script `22` constructs the two additional descriptive figures. Some scripts consume outputs from the upstream preparation workspace; there is no claim that this repository alone recreates those prepared inputs. Refer to the manuscript Methods and its supporting workbook for cohort criteria and numeric outputs.

No direct personal identifiers, access tokens or source expression archives are distributed in this repository. Statistical associations from RNA-derived scores do not demonstrate xenobiotic flux, cell-specific metabolism or treatment response.
